About the Analytics

Historical consumption analysis uses the available Model A daily electricity dataset.

Model A represents pooled historical average household consumption and not an individual household's actual electricity usage.

Model B performance metrics are based on a synthetic household electricity dataset. Real-world generalisation has not been independently verified.

Model A and Model B predict different targets. Their R² values should therefore be interpreted separately.
